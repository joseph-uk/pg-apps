## Side Bar Forecast Views
* Setting up favourite forecast tools
  * thermal
  * wind
    * altitude
  * rain
  * cloudbase
* On the day forecast/nowcast tools
  * radar+
    * radar
    * satellite
* More detail tools
  * Solar power
  * wind gusts

### How to pin favourite forecast views
there are actually loads - you can configure and pin your favourites

# Location Forecast Views
when viewing a location, you will default to basic view
you can also try wind, meteo and airgram

# Models and Compare Models
you can choose differnt models
there is a "compare models" section which lets you compare basic forecast for a locatoin

# Sounding
You can view a skew T or a special windy version which is not skewed
Dont forget to zoom right in!

# Viewing Paragliding Takeoffs
you can make the map show paragliding launches
you can "heart" certain locations to make them easier to find and see on the map
you can set up alerts for favourites - can be useful
