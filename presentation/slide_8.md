*   **1. Flybubble Weather:**
    *   Combines RASP data (Stars, Wind) with site database (Paragliding Earth). Green/Red blobs for potential site flyability.
    *   **Pros:** Good for *generating ideas* of where might work based *only* on RASP.
    *   **Cons/Caveats:**
        *   **Relies solely on RASP** (Discard if RASP looks wrong via Windy).
        *   Site wind tolerances can be **very inaccurate** (e.g., shows Semerwater flyable in NNE). *Your site knowledge is essential.* Treat as idea generator only.
    *   Link: [https://flybubble.com/weather](https://flybubble.com/weather)
*   **2. Paragliding Map:**
    *   Global site database + basic forecast (Windfinder?). Smiley faces for *current* flyability (paid for future).
    *   **Pros:** Useful site database reference.
    *   **Cons:** Forecast source unclear, optimized for mountains (can show flyable in zero wind - bad for Dales!), uses Paragliding Earth data. Less useful for planning.
    *   Link: [https://paraglidingmap.com](https://paraglidingmap.com)
*   **3. Paragliding Earth:**
    *   The *underlying database* for many site maps. Raw site info (coordinates, descriptions).
    *   Link: [https://paraglidingearth.com](https://paraglidingearth.com)
