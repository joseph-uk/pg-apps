# Paragliding Apps

This is designed to be a user friendly database of apps and websites related to paragliding

## [PUBLIC URL https://joseph-uk.github.io/pg-apps/](https://joseph-uk.github.io/pg-apps/)

## Contribute

source data is managed via [google sheet](https://docs.google.com/spreadsheets/d/1JVbFwMKylrgj8e3HUP-ummgBl9O2EVyBKyMx6-xT-Qw/edit?gid=0#gid=0)

sheet updates automatically create pull requests here to be merged into this system

## App Rich Descriptions

rich data resides in [./data/apps](./data/apps)

to update this information, you will need to fork this repo, make your edits and then do a pull request

https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/getting-started/about-collaborative-development-models#fork-and-pull-model
